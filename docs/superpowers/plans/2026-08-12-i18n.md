# Internationalisation 5 langues — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre l'interface de Lehaim v2 disponible en français, anglais, espagnol, hébreu et russe, avec un garde-fou qui empêche de publier une fonctionnalité incomplètement traduite.

**Architecture:** `next-intl` sans préfixe d'URL. La langue est résolue une fois dans le middleware (cookie → `profiles.locale` → `Accept-Language` → `fr`) et déposée dans un cookie que le reste de l'app lit sans requête supplémentaire. L'hébreu bascule le document en RTL ; les polices sont substituées uniquement là où Fredoka et Nunito ne couvrent pas l'écriture.

**Tech Stack:** Next.js 16.3 (App Router, RSC), React 19.2, Tailwind v4, Supabase, `next-intl` 4.13.6.

## Global Constraints

- Langue source : **français**, dans `messages/fr.json`. Il fait autorité sur la liste des clés.
- Les cinq codes de langue sont exactement : `fr`, `en`, `es`, `he`, `ru`.
- Seul `he` est RTL.
- `next-intl` en version `^4.13.6` (peer dependency `next: ^16.0.0` vérifiée).
- Aucune migration ne modifie de colonne existante : uniquement `add column if not exists`, nullable, comme `0007`.
- Une langue incomplète retombe sur le français. **Jamais** de clé brute affichée à l'écran.
- Le projet n'a pas de harnais de test. La vérification passe par `npm run build`, `npm run lint`, `npm run i18n:check` et le navigateur.
- Commit après chaque tâche.

- [ ] **Step 2 : Créer le module de langue**

Créer `lib/i18n/locale.ts` :

```ts
export const LOCALES = ["fr", "en", "es", "he", "ru"] as const;

export type Locale = (typeof LOCALES)[number];

export const DEFAULT_LOCALE: Locale = "fr";

/** Seul l'hébreu s'écrit de droite à gauche. */
export const RTL_LOCALES: readonly Locale[] = ["he"];

/** Cookie où la langue résolue est déposée par le middleware. */
export const LOCALE_COOKIE = "NEXT_LOCALE";

export function isLocale(value: unknown): value is Locale {
  return typeof value === "string" && (LOCALES as readonly string[]).includes(value);
}

export function dirFor(locale: Locale): "ltr" | "rtl" {
  return RTL_LOCALES.includes(locale) ? "rtl" : "ltr";
}

/**
 * Première langue supportée dans l'en-tête du navigateur, par ordre de
 * préférence déclarée. « fr-CA » compte pour « fr ».
 */
export function localeFromAcceptLanguage(header: string | null): Locale | null {
  if (!header) return null;

  const ranked = header
    .split(",")
    .map((part) => {
      const [tag, q] = part.trim().split(";q=");
      return { tag: tag.trim().toLowerCase(), q: q ? Number(q) : 1 };
    })
    .sort((a, b) => b.q - a.q);

  for (const { tag } of ranked) {
    const base = tag.split("-")[0];
    if (isLocale(base)) return base;
  }
  return null;
}
```

- [ ] **Step 4 : Créer la configuration de requête**

Créer `i18n/request.ts` :

```ts
import { cookies, headers } from "next/headers";
import { getRequestConfig } from "next-intl/server";
import {
  DEFAULT_LOCALE,
  LOCALE_COOKIE,
  isLocale,
  localeFromAcceptLanguage,
} from "@/lib/i18n/locale";

/**
 * Le middleware a normalement déjà posé le cookie. On refait quand même le
 * repli sur l'en-tête pour les requêtes qu'il ne couvre pas (fichiers
 * statiques exclus du matcher, premier passage).
 */
export default getRequestConfig(async () => {
  const cookieStore = await cookies();
  const fromCookie = cookieStore.get(LOCALE_COOKIE)?.value;

  let locale = isLocale(fromCookie) ? fromCookie : null;

  if (!locale) {
    const headerStore = await headers();
    locale = localeFromAcceptLanguage(headerStore.get("accept-language"));
  }

  locale ??= DEFAULT_LOCALE;

  const fr = (await import(`../messages/fr.json`)).default;
  const messages =
    locale === DEFAULT_LOCALE
      ? fr
      : deepMerge(fr, (await import(`../messages/${locale}.json`)).default);

  return { locale, messages };
});

/**
 * Le français sert de socle : une clé absente d'une autre langue retombe sur
 * sa version française plutôt que d'afficher la clé brute à l'écran.
 */
function deepMerge(
  base: Record<string, unknown>,
  override: Record<string, unknown>,
): Record<string, unknown> {
  const result: Record<string, unknown> = { ...base };
  for (const [key, value] of Object.entries(override)) {
    const current = result[key];
    result[key] =
      current && typeof current === "object" && value && typeof value === "object"
        ? deepMerge(current as Record<string, unknown>, value as Record<string, unknown>)
        : value;
  }
  return result;
}
```

Ce repli est ce qui tient la contrainte globale « jamais de clé brute affichée ».
Sans lui, `next-intl` afficherait `onboarding.welcome.title` à l'écran dès qu'une
clé manque.

Modifier `proxy.ts`. Après le `const { data: { user } } = await supabase.auth.getUser();` existant et **avant** le `return response`, insérer :

```ts
  // La langue n'est résolue qu'une fois : ensuite le cookie fait foi, ce qui
  // évite une lecture de `profiles` à chaque requête.
  if (!isLocale(request.cookies.get(LOCALE_COOKIE)?.value)) {
    let locale: Locale | null = null;

    if (user) {
      const { data } = await supabase
        .from("profiles")
        .select("locale")
        .eq("id", user.id)
        .maybeSingle();
      if (isLocale(data?.locale)) locale = data.locale;
    }

    locale ??= localeFromAcceptLanguage(request.headers.get("accept-language"));
    locale ??= DEFAULT_LOCALE;

    response.cookies.set(LOCALE_COOKIE, locale, {
      path: "/",
      maxAge: 60 * 60 * 24 * 365,
      sameSite: "lax",
    });
  }
```

- [ ] **Step 1 : Écrire le vérificateur de parité**

Créer `scripts/i18n-check.mjs` :

```js
#!/usr/bin/env node
import { readFileSync } from "node:fs";

const LOCALES = ["fr", "en", "es", "he", "ru"];
const SOURCE = "fr";

/** Aplatit { a: { b: "x" } } en ["a.b"]. */
function keysOf(object, prefix = "") {
  return Object.entries(object).flatMap(([key, value]) => {
    const path = prefix ? `${prefix}.${key}` : key;
    return value !== null && typeof value === "object" ? keysOf(value, path) : [path];
  });
}

function load(locale) {
  return JSON.parse(readFileSync(new URL(`../messages/${locale}.json`, import.meta.url), "utf8"));
}

const source = new Set(keysOf(load(SOURCE)));
let failed = false;

for (const locale of LOCALES.filter((l) => l !== SOURCE)) {
  const keys = new Set(keysOf(load(locale)));
  const missing = [...source].filter((k) => !keys.has(k));
  const orphan = [...keys].filter((k) => !source.has(k));

  if (missing.length) {
    failed = true;
    console.error(`\n✗ ${locale} — ${missing.length} clé(s) manquante(s) :`);
    for (const key of missing) console.error(`    ${key}`);
  }
  if (orphan.length) {
    failed = true;
    console.error(`\n✗ ${locale} — ${orphan.length} clé(s) orpheline(s), absente(s) du français :`);
    for (const key of orphan) console.error(`    ${key}`);
  }
}

if (failed) {
  console.error("\nTraductions incomplètes. Lancer `npm run i18n:missing`.\n");
  process.exit(1);
}

console.log(`✓ ${source.size} clés, cohérentes sur ${LOCALES.length} langues.`);
```

```js
#!/usr/bin/env node
import { readFileSync } from "node:fs";

const LOCALES = ["fr", "en", "es", "he", "ru"];
const SOURCE = "fr";

function entriesOf(object, prefix = "") {
  return Object.entries(object).flatMap(([key, value]) => {
    const path = prefix ? `${prefix}.${key}` : key;
    return value !== null && typeof value === "object"
      ? entriesOf(value, path)
      : [[path, value]];
  });
}

function load(locale) {
  return JSON.parse(readFileSync(new URL(`../messages/${locale}.json`, import.meta.url), "utf8"));
}

const source = entriesOf(load(SOURCE));

for (const locale of LOCALES.filter((l) => l !== SOURCE)) {
  const present = new Set(entriesOf(load(locale)).map(([k]) => k));
  const todo = source.filter(([key]) => !present.has(key));
  if (!todo.length) continue;

  console.log(`\n=== ${locale} — ${todo.length} à traduire ===`);
  for (const [key, value] of todo) console.log(`${key}\t${value}`);
}
```

- [ ] **Step 6 : Détecter le texte écrit en dur**

C'est le second mécanisme prévu par la spec : attraper la chaîne oubliée *avant*
qu'elle manque dans quatre langues. La spec autorisait une règle ESLint ou un
script maison ; on prend le script, qui ne dépend d'aucune intégration en flat
config et se branche sur la même commande.

Créer `scripts/i18n-scan.mjs` :

```js
#!/usr/bin/env node
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join } from "node:path";

const ROOTS = ["app", "components"];
// Écrans de revue interne, non traduits volontairement.
const SKIP = [/\/legacy\//, /\/ecrans\//, /\/etats\//];

// Texte visible entre deux balises : >Bonjour< mais pas >{name}< ni >  <.
const JSX_TEXT = /^\s*>[^<>{}]*\p{L}{3}[^<>{}]*<\s*$/u;

function walk(dir) {
  return readdirSync(dir).flatMap((entry) => {
    const path = join(dir, entry);
    return statSync(path).isDirectory() ? walk(path) : [path];
  });
}

const offenders = [];

for (const root of ROOTS) {
  for (const file of walk(root)) {
    if (!file.endsWith(".tsx")) continue;
    if (SKIP.some((pattern) => pattern.test(`/${file}`))) continue;

    readFileSync(file, "utf8")
      .split("\n")
      .forEach((line, index) => {
        const match = line.match(/>[^<>{}]*\p{L}{3}[^<>{}]*</u);
        if (match && JSX_TEXT.test(match[0])) {
          offenders.push(`${file}:${index + 1}  ${match[0].trim()}`);
        }
      });
  }
}

if (offenders.length) {
  console.error(`\n✗ ${offenders.length} chaîne(s) écrite(s) en dur dans le JSX :`);
  for (const line of offenders) console.error(`    ${line}`);
  console.error("\nLes déplacer dans messages/fr.json et les lire via t().\n");
  process.exit(1);
}

console.log("✓ Aucun texte en dur dans le JSX.");
```

```sql
-- Lehaim — langue d'affichage
-- Colonne nullable et sans valeur par défaut : la v1 ne la voit pas.
-- Idempotent.
-- ============================================================
alter table public.profiles add column if not exists locale text;

do $$
begin
  if not exists (select 1 from pg_constraint where conname = 'profiles_locale_check') then
    alter table public.profiles add constraint profiles_locale_check
      check (locale in ('fr','en','es','he','ru'));
  end if;
end
$$;
```

- [ ] **Step 3 : Écrire la server action**

Créer `app/reglages/locale-actions.ts` :

```ts
"use server";

import { cookies } from "next/headers";
import { revalidatePath } from "next/cache";
import { createClient } from "@/lib/supabase/server";
import { LOCALE_COOKIE, isLocale } from "@/lib/i18n/locale";

/** Écrit le choix dans le cookie et, si la personne a un compte, dans son profil. */
export async function setLocale(formData: FormData): Promise<void> {
  const locale = String(formData.get("locale") ?? "");
  if (!isLocale(locale)) return;

  const cookieStore = await cookies();
  cookieStore.set(LOCALE_COOKIE, locale, {
    path: "/",
    maxAge: 60 * 60 * 24 * 365,
    sameSite: "lax",
  });

  const supabase = await createClient();
  const {
    data: { user },
  } = await supabase.auth.getUser();

  if (user) await supabase.from("profiles").update({ locale }).eq("id", user.id);

  revalidatePath("/", "layout");
}
```
